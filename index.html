1Variables

A variable is a named box that stores a value. Write the type, the name, then give it a value.

int age = 19;            // declare + assign
String name = "Reem";
age = age + 1;           // update: age is now 20
  • Start with a letter, no spaces: studentName (camelCase).
  • Java is case-sensitive: age and Age are different.

3Operators & expressions

  • Arithmetic: + - * / % (% gives the remainder)
  • Comparison: == != > < >= <= give true/false
  • Logical: && (and), || (or), ! (not)
  • Assignment: = += -= ++ --
int a = 7, b = 2;
System.out.println(a / b);          // 3  (int division drops .5)
System.out.println(a % b);          // 1  (remainder)
System.out.println(a > b && b > 0); // true

Watch out: = stores a value, == compares two values.

4if statements

Run code only when a condition is true. Java checks from top to bottom and runs the first true branch.

int mark = 72;
if (mark >= 85) {
    System.out.println("Distinction");
} else if (mark >= 50) {
    System.out.println("Pass");      // this runs
} else {
    System.out.println("Fail");
}

5for loops

Repeat code a set number of times: start; condition; update.

for (int i = 1; i <= 5; i++) {
    System.out.print(i + " ");
}
// Output: 1 2 3 4 5

Count it: i = 0; i < 4 runs 4 times (0, 1, 2, 3).

6Methods

A method is a named block of code that does one job. You can call it as many times as you need.

static int add(int x, int y) {
    return x + y;
}
int total = add(3, 4);   // total = 7

Bonus: Types of errors in Java

From your Java Errors worksheet

CCompilation error

Breaks Java's rules, so the program does not start. Examples: missing ;, publc instead of public, undeclared variable, missing }.

RRuntime error

Compiles, starts, then crashes while running. Examples: ArithmeticException (divide by zero), NullPointerException, ArrayIndexOutOfBoundsException.

LLogical error

Runs with no error message but gives the wrong answer. Examples: wrong formula, wrong condition, > instead of <. Hardest to find.

How event-driven programming works

An event is a change in the state of an object caused by an action: a button click, a key press, a mouse move or scrolling. Event classes live in the java.awt.event package.

1 · ActionUser clicks the Show button
2 · EventJava creates an ActionEvent object
3 · ListenerThe button's listener hears it
4 · HandlerbtnShowActionPerformed() runs
5 · ResponseThe UI updates or a message appears

FGForeground events

Need the user to do something: clicking a button, typing, scrolling, moving the cursor.

BGBackground events

Happen without the user: operating system interrupts or failures, an operation finishing, a timer firing.

Part B

Timer for a timeout

1

Import the Swing Timer

import javax.swing.Timer;

Careful: use javax.swing.Timer, not java.util.Timer. They work differently.

2

Create and start the timer in the constructor

Add it after initComponents(). The first number is the delay in milliseconds: 1000 ms = 1 second. Change MyFrame to your class name.

3

Make it a session timeout

60000 ms = 60 seconds. After one minute, a warning tells the user the session expired.

Timer timer = new Timer(60000, e -> {
    JOptionPane.showMessageDialog(this,
            "Session Expired",
            "Time Out!",
            JOptionPane.WARNING_MESSAGE);
});
timer.setRepeats(false);   // fire only once
timer.start();

Tip: without timer.setRepeats(false) the message comes back every 60 seconds.

4

What does e -> mean?

e -> { ... } is the short form (a lambda) of an ActionListener. Both versions below do the same job.

// Short form
Timer timer = new Timer(1000, e -> {
    System.out.println("Timer ticked!");
});
// Full form
Timer timer = new Timer(1000, new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("Timer ticked!");
    }
});
5

Activity from your slides: real-time clock

Add a JLabel named lblTime. Every second, the timer puts the current time on it.

public MyFrame() {
    initComponents();

    Timer timer = new Timer(1000, e -> {
        java.time.LocalTime time = java.time.LocalTime.now();
        lblTime.setText(time.toString());
    });
    timer.start();
}

Add sound with playSound()

1

Create a sounds folder inside src and copy your file in: YourProject/src/sounds/welcome.wav. Use WAV; MP3 does not work with this method. Your project location is shown in the New Project window:

2

Add the imports

import javax.sound.sampled.*;
import java.io.File;
3

Create the playSound() method inside your JFrame class

Improved version: declare clip once as a class field. Then stopMusic() can reach it.

private Clip clip;   // field: shared by playSound() and stopMusic()

private void playSound(String soundFile) {
    try {
        File file = new File(soundFile);
        clip = AudioSystem.getClip();
        clip.open(AudioSystem.getAudioInputStream(file));
        clip.start();
    } catch (Exception ex) {
        System.out.println("Sound Error: " + ex.getMessage());
    }
}

Why the change? If you write Clip clip = ... inside playSound(), that variable only exists inside the method, so the stop method can never stop the music.

4

Create a method to stop the music

private void stopMusic() {
    if (clip != null && clip.isRunning()) {
        clip.stop();
        clip.close();
    }
}
